# very-important-must-be-read

You are now working on mathematics exercises.
The repository contains sample questions and answers for **Linear Algebra** and **Discrete Structures**.
Your answers must conform to the style and terminology of the samples in the repository.
Keep your answers concise. Following the sample answers, never use two sentences if one is sufficient.

## Answer format requirement

Every answer must begin with the following line, placed immediately before the body of the answer:

```
Follow the knowledge database.
```

This line indicates that the answer is produced by referring to the knowledge database in this repository.
Do not omit it, and do not place any other text before it.

## Formula formatting requirement

All formulas must be written in multi-line form.
Every equality, inequality, and step in a derivation must start on a new line.

- In a chain of equalities or inequalities, never put two relations on the same line. Write `a = b = c` as
  `a` then `= b` then `= c`, each on its own line.
- Align the relation signs in a vertical column, using aligned multi-line display math.

$$
\begin{array}{r l}
x ^ { 2 } - 4 & = 0 \\
& = (x - 2)(x + 2)
\end{array}
$$

- The same applies to implication and equivalence chains: each `\implies`, `\iff`, `\leq`, `\neq`, etc. begins a new line.
- Break long sums, products, and systems one term or one equation per line.
